INSTASAVE

UI / UX BLUEPRINT SET — SCREEN FLOOR PLANS
Set of dimensioned screen "floor plans," drawn the way a building's plans are drawn — fixed zones, numbered elements, a legend/schedule per sheet, and a title block. Companion to UI_UX_DESIGN.md (tokens/visual spec) and UI_ARCHITECTURE.md (code structure). Units below are dp (density-independent pixels), the Android layout unit — same as an architectural plan uses feet/meters.
01 Home Screen — paste / fetch / recent
02 Resolution Picker Sheet — modal quality selector
03 Carousel Grid — modal, multi-select variant
04 Download Queue Screen — active/queued downloads
05 History Screen — full download history
06 Settings Screen
