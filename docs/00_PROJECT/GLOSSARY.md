# Technical Glossary — Seal / InstaFlow

| Term | Definition |
| :--- | :--- |
| **yt-dlp** | A command-line program to download videos from YouTube and other video sites. The primary extraction engine used by Seal. |
| **youtubedl-android** | An Android library (forked by JunkFood02) that bundles compiled `yt-dlp`, `ffmpeg`, and `aria2c` native C/C++ binaries with Python runtime for Android via JNI. |
| **aria2c** | A lightweight multi-protocol & multi-source command-line download utility used for high-speed multi-threaded downloads in `yt-dlp`. |
| **FFmpeg** | A complete, cross-platform solution to record, convert, and stream audio and video, used by `yt-dlp` for remuxing video and audio streams. |
| **Koin** | A pragmatic lightweight dependency injection framework for Kotlin and Jetpack Compose. |
| **MMKV** | An efficient, small mobile key-value storage framework developed by Tencent, replacing Android SharedPreferences and DataStore. |
| **Room** | An Android Jetpack persistence library providing an abstraction layer over SQLite. |
| **SAF (Storage Access Framework)** | Android API that allows users to browse and open/save files across document providers. |
| **Single-Activity Architecture** | Design pattern where the entire application uses a single `Activity` (`MainActivity`) with screens rendered via Jetpack Compose destinations. |
